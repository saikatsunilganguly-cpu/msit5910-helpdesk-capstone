**Author:** Saikat Sunil Ganguly
**Program:** MSIT 5910, University of the People
**Instructor:** Dr. Stella Whyte

## Project Summary

This repository tracks the design and documentation artifacts for a capstone
project investigating how a simplified ticket categorisation model and
structured triage workflow can improve routing consistency and reduce
avoidable delays in IT helpdesk environments. The project is conceptual and
tool-agnostic: it does not build or deploy a production helpdesk system.

## Branching Approach

- **main** — contains reviewed, stable documents and final submission artifacts.
- **development** — contains active drafts, architecture revisions, requirements
  changes, and workflow updates before review and merge into `main`.

This separates work-in-progress material from stable deliverables and
supports traceability of design decisions across the capstone timeline.
