# Functional Requirements

| ID  | Functional Requirement |
|-----|--------------------------|
| FR1 | The system shall provide guided, plain-language prompts that allow users to select one of at least five standard ticket categories. |
| FR2 | The system shall capture a structured ticket record containing category, impact, urgency, relevant description, and submission timestamp. |
| FR3 | The system shall apply a standard triage workflow that routes tickets using category, priority, impact, and urgency. |
| FR4 | The system shall flag security-sensitive or high-impact tickets for an immediate escalation path. |
| FR5 | The system shall record ticket category, priority, assignment, status changes, and resolution information for analysis. |
| FR6 | The system shall produce reports on reassignment rate, backlog size, resolution-time trends, and categorisation quality. |
| FR7 | The system shall enforce role-based access control and maintain an audit trail for ticket assignment and escalation changes. |
